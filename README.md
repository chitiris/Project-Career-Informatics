# Καριέρες Πληροφορικής

**Τι μπορώ να κάνω με πτυχίο Πληροφορικής;**

Ένα διαδραστικό brainstorming board με τους επαγγελματικούς τομείς και τις θέσεις εργασίας για αποφοίτους Πληροφορικής στην Ελλάδα. Για κάθε θέση δείχνει τι καθήκοντα έχει, ποιες γνώσεις χρειάζεται και πού θα βρεις πλήρες job description.

## Τι περιέχει

- **20 τομείς** και **124 θέσεις εργασίας**, από την ανάπτυξη λογισμικού και τα δεδομένα μέχρι τη διδασκαλία, το Δημόσιο και τις πωλήσεις τεχνολογίας.
- Για κάθε θέση:
  - μια σύντομη περιγραφή,
  - τα βασικά **καθήκοντα**,
  - τις **γνώσεις και δεξιότητες** που ζητούνται,
  - links σε **job descriptions** από Workable, Indeed και SHRM, όπου υπάρχει αντίστοιχο πρότυπο.
- Οι τομείς με την ένδειξη **ΦΕΚ** βασίζονται στα επαγγελματικά δικαιώματα των πτυχιούχων Πληροφορικής, όπως ορίζονται στο Π.Δ. 44/2009.

## Πώς τη χρησιμοποιείς

1. Άνοιξε τη σελίδα.
2. Πάτα σε ένα κουτί για να δεις την περιγραφή του τομέα και τις θέσεις του.
3. Πάτα σε μια θέση για να δεις καθήκοντα, γνώσεις και links.

Η σελίδα δουλεύει σε υπολογιστή και κινητό, σε ανοιχτό και σκοτεινό θέμα.

## Πώς την ανοίγεις

**Τοπικά:** κατέβασε το repository και άνοιξε το `index.html` σε έναν browser. Δεν χρειάζεται εγκατάσταση.

**Online με GitHub Pages:**
1. Στο repository πήγαινε στα **Settings → Pages**.
2. Στο **Source** επίλεξε **Deploy from a branch**, branch `main` και φάκελο `/ (root)`.
3. Πάτα **Save**. Σε λίγα λεπτά η σελίδα θα είναι διαθέσιμη στο `https://<όνομα-χρήστη>.github.io/<όνομα-repository>/`.

## Δομή

```
index.html          Η σελίδα (HTML, CSS, JavaScript και δεδομένα σε ένα αρχείο)
scripts/check.js    Έλεγχος δεδομένων (διπλότυπα, θέσεις χωρίς περιγραφή, διάταξη)
CLAUDE.md           Τεχνικές σημειώσεις και ιστορικό αποφάσεων για όποιον συνεχίσει τη δουλειά
README.md           Αυτό το αρχείο
```

## Πώς προσθέτεις ή αλλάζεις θέσεις

Τα δεδομένα βρίσκονται μέσα στο `<script>` του `index.html`:

- Το **`AREAS`** περιέχει τα κουτιά και τις θέσεις τους.
- Το **`JD`** περιέχει το job description κάθε θέσης, με κλειδί τον τίτλο της.

Αναλυτικές οδηγίες υπάρχουν στο [`CLAUDE.md`](CLAUDE.md). Μετά από κάθε αλλαγή τρέξε τον έλεγχο (χρειάζεται [Node.js](https://nodejs.org/)):

```bash
node scripts/check.js
```

## Πηγές

- **Επαγγελματικά δικαιώματα:** Π.Δ. 44/2009, ΦΕΚ Α΄ 58/8.4.2009, «Επαγγελματική κατοχύρωση των διπλωματούχων μηχανικών και των πτυχιούχων πανεπιστημιακής εκπαίδευσης στα αντικείμενα πληροφορικής και τηλεπικοινωνιών».
- **Job descriptions:** [Workable](https://resources.workable.com/job-descriptions/), [Indeed](https://www.indeed.com/hire/job-description-list), [SHRM](https://www.shrm.org/topics-tools/tools/job-descriptions).
- **Θέσεις στην ελληνική αγορά:** αγγελίες σε [kariera.gr](https://www.kariera.gr/), [skywalker.gr](https://www.skywalker.gr/el), [Randstad](https://www.randstad.gr/), [Indeed Ελλάδας](https://gr.indeed.com/) και [freelancer.gr](https://www.freelancer.gr/job/) (Οκτώβριος 2026).
- **Αρχική χαρτογράφηση τομέων:** οδηγοί καριέρας για αποφοίτους Πληροφορικής (2026) και ημερίδες σταδιοδρομίας του Τμήματος Πληροφορικής ΑΠΘ.

Τα καθήκοντα και οι γνώσεις κάθε θέσης είναι συνοπτική περιγραφή και όχι αντιγραφή των πηγών. Για το πλήρες κείμενο ακολούθησε τα links. Η αγορά εργασίας αλλάζει γρήγορα, οπότε οι θέσεις και οι απαιτήσεις τους ισχύουν για τον Οκτώβριο του 2026.
